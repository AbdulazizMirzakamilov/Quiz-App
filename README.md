# 📚 WPF Quiz Master App (BDQuiz)

Это настольное приложение, разработанное для создания, управления и прохождения интерактивных викторин (тестов). Приложение обеспечивает полный контроль доступа и хранение данных в надёжной базе PostgreSQL.

## ✨ Основные возможности

* **Аутентификация и Регистрация:** Безопасный вход пользователей с использованием надёжного хеширования паролей (SHA256).
* **Контроль доступа (RBAC):** Разграничение прав пользователей. Только **Администраторы** имеют возможность создавать, редактировать и удалять викторины. Обычные пользователи могут только проходить их.
* **Полное управление викторинами (CRUD):**
    * Создание, просмотр, редактирование и удаление викторин, вопросов и вариантов ответов.
* **Прохождение викторин:** Пользователи могут выбирать викторины и получать оценку по завершении.
* **Хранение данных:** Все данные о викторинах, вопросах и результатах попыток надёжно хранятся в PostgreSQL.

## 💻 Технологический стек

* **Платформа:** .NET 10.0 (WPF)
* **Язык:** C#
* **База данных:** PostgreSQL
* **ORM:** Entity Framework Core (Npgsql Provider)
* **Безопасность:** Хеширование паролей SHA256.

## 🚀 Установка и запуск

Для запуска приложения необходимо настроить подключение к базе данных.

### 1. Подготовка базы данных

1.  Убедитесь, что у вас установлен и запущен **PostgreSQL**.
2.  Создайте базу данных.
3.  Выполните SQL-скрипты для создания всех необходимых таблиц.

### 2. Настройка проекта

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/AbdulazizMirzakamilov/Quiz-App
    ```
2.  Откройте файл **`Models/DataBaseContext.cs`**.
3.  Проверьте и обновите строку подключения в методе `OnConfiguring` под ваши данные (`Username` и `Password`).

### 3. Запуск

1.  Откройте файл `.slnx` в **Visual Studio**.
2.  Скомпилируйте и запустите проект (F5).
3.  При первом запуске зарегистрируйте пользователя и отметьте его как Администратора для получения доступа к инструментам редактирования.
