# 📚 Quiz App | Настольное приложение на WPF

Приложение предназначено для создания, управления и прохождения викторин (тестов) с реализацией ролевой модели доступа и надёжным хранением данных.

---

### ✨ Ключевые особенности

| Функция | Описание |
| :--- | :--- |
| **🔐 Безопасность и Аутентификация** | Система входа/регистрации пользователей с защитой паролей (SHA256). |
| **🧑‍⚖️ Ролевой Контроль Доступа (RBAC)** | Чёткое разделение прав: **Администраторы** могут создавать/редактировать викторины, обычные пользователи — только проходить тесты. |
| **✍️ Полный цикл управления (CRUD)** | Возможность полного создания, изменения и удаления викторин, вопросов и вариантов ответов. |
| **📊 Учет Результатов** | Фиксация попыток прохождения и выставление оценки по завершении теста. |

---

### 💻 Технологический стек

| Категория | Технология | Примечание |
| :--- | :--- | :--- |
| **Фронтенд** | WPF | Настольный клиентский интерфейс. |
| **Платформа** | .NET 10.0 | Современная среда разработки. |
| **База данных** | PostgreSQL | Надёжная реляционная СУБД. |

### ⚙️ Инструкция по развертыванию

Для начала работы необходимо подготовить сервер PostgreSQL и восстановить начальную структуру базы данных.

#### Шаг 1: Подготовка окружения

1.  Установите и запустите **PostgreSQL** (убедитесь, что сервер доступен).
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/AbdulazizMirzakamilov/Quiz-App
    ```

#### Шаг 2: Восстановление базы данных (Дамп)

Проект использует предварительно созданную структуру БД.

1.  Создайте на сервере PostgreSQL **пустую** базу данных.
2.  Воспользуйтесь файлом **`backup_quizapp.sql`** (находится в корне репозитория), чтобы восстановить структуру таблиц и базовые данные.
    * *Для восстановления можно использовать утилиту `psql` или графические инструменты, такие как pgAdmin.*

#### Шаг 3: Настройка подключения

1.  Откройте проект в Visual Studio.
2.  Перейдите к файлу **`Models/DataBaseContext.cs`**.
3.  Обновите строку подключения в методе `OnConfiguring` под ваши данные (`Username` и `Password`):

    ```csharp
    optionsBuilder.UseNpgsql("Host=localhost;Port=5432;Database=QuizApp;Username=postgres;Password=your_password");
    ```

#### Шаг 4: Сборка и запуск

1.  Откройте файл решения **`.slnx`** в Visual Studio.
2.  Соберите проект и запустите приложение (F5).
3.  Если вы успешно восстановили дамп, вы можете сразу зарегистрировать нового пользователя.
